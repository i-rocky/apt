Add the repository

curl -fsSL https://apt.clapbox.net/rocky-oss.gpg \
  | sudo tee /usr/share/keyrings/rocky-oss.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/rocky-oss.gpg] https://apt.clapbox.net stable main" \
  | sudo tee /etc/apt/sources.list.d/rocky-oss.list
sudo apt update

Works on Debian, Ubuntu, and derivatives, on amd64 and arm64. Every release is signed; apt verifies the signature against the key you installed — fingerprint C7752A90E90DC6FE1CD1699FEE6ECE90DAAFB8E6.

How it's built

Each tool's release workflow builds .deb packages and attaches them to its GitHub release with SHA256 checksums. The publisher pulls those debs, regenerates the apt metadata, signs it, and uploads the tree to Cloudflare R2 — so what apt installs is byte-for-byte what the tool's release CI built. The whole pipeline is open source.
